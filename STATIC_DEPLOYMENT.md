# Legendary Management MEA - Static Deployment

1. Run: `pnpm build:static`
2. Upload the **CONTENTS** of `out/` to `public_html` OR upload/extract `legendary-management-mea-static-demo.zip` directly into `public_html`.
3. Ensure `index.html` is directly inside `public_html`.
4. Do **NOT** configure a Node.js application for this static demo.
5. If replacing an older deployment: backup and delete old site files first while preserving unrelated domain configuration.
